# The Savage NFT — Frontend

Vercel-ready Next.js frontend containing the homepage, About page, Collection page, responsive motion design, and NFT artwork.

1. Upload this folder to its own GitHub repository and import it into Vercel.
2. Add `NEXT_PUBLIC_API_URL` with the deployed backend URL.
3. Redeploy after saving the variable.

Local setup: copy `.env.example` to `.env.local`, run `npm install`, then `npm run dev`.
